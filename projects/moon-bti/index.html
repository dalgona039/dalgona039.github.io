문BTI

Literary Personality Test App (MoonBTI)

독서 취향을 MBTI 프레임으로 분석해 대표 작가·작품으로 연결하는 크로스플랫폼 Flutter 앱.

Overview

읽는 사람의
16가지 얼굴.

독서 취향에는 성향이 묻어납니다. 문BTI는 24문항 리커트 척도 진단으로 사용자의 문학 취향을 16가지 MBTI 유형으로 매핑하고, 각 유형을 대표 작가 페르소나·추천 작품·명구절로 연결합니다.

뉴모피즘 기반의 감성 디자인 아이덴티티와 접근성을 모두 고려한 단일 화면 플로우 앱입니다.

User Journey · Features

진단에서 해석까지

홈 화면→ 24문항 응답→ 문항별 확인→ 결과 · 작가 유형 · 추천작 · 해석 노트
  • 0124문항 진단 — E/I·S/N·T/F·J/P 각 6문항의 리커트 척도.
  • 0216가지 결과 매핑 — 작가 페르소나·추천 작품·명구절로 연결.
  • 03뉴모피즘 디자인 — 감성적인 디자인 아이덴티티를 커스텀 컴포넌트로 구현.
  • 04접근성 강화 — Semantics 라벨, 최소 터치 영역, 스크린리더 지원.
  • 05디자인 시스템 — app_tokens.dart로 색상·타이포·간격을 토큰화.
