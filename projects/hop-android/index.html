Overview

공문서 표준을
모바일로.

국내 공문서 표준 포맷인 한글 HWP는 모바일 접근성이 취약합니다. HOP Android는 데스크톱 HOP 프로젝트의 Android 포트/포크로, Rust rhwp 엔진을 통해 HWP/HWPX를 직접 파싱·렌더링합니다.

Tauri v2의 경량 웹뷰 위에서 네이티브에 가까운 성능을 내며, GitHub Releases를 통해 Android 빌드를 배포 완료했습니다.

Methodology · Core Capabilities

Rust 엔진 + 모바일 웹뷰

  • 01HWP/HWPX 파싱·렌더링 — Rust rhwp 엔진이 문서 구조를 해석합니다.
  • 02Android 인텐트 기반 파일 열기 — Scoped Storage I/O로 안전하게 파일에 접근합니다.
  • 03모바일 UX 최적화 — 안드로이드 네이티브에 가까운 인터랙션 경험을 제공합니다.
  • 04CI/CD 자동화 — .github/workflows로 빌드·배포 파이프라인을 구성했습니다.
  • 05Monorepo 구조 — pnpm workspace 기반으로 패키지를 관리합니다.
HWP/HWPX→ rhwp (Rust)→ WASM→ Tauri WebView→ Android Render
